# 収益化プラン（最短ルート）

## 現実的な前提
- Amazonアソシエイト（日本）は **申請から180日以内に適格販売3件** で正式承認。未達だと取消（再申請は可能）。
- 新規ドメインの検索流入は通常 **3〜6か月** かかる。→ 最初の3件は **SNS経由** で取りにいき、並行してSEO記事を貯める。
- 紹介料は「リンク経由で24時間以内にカートに入れて購入された商品すべて」が対象。リンク先の商品以外が売れても報酬になる。
- 自己購入・家族友人への購入依頼は規約違反。やらない。

## 戦略
1. **ジャンル**：在宅ワーク・デスク周り（購入単価が中〜高、"選び方"検索が多く、季節変動が少ない、継続的に新製品が出る）
2. **記事の型**：「〇〇 選び方 / 失敗 / 付かない / 違い」＝ 購入直前の不安を解消する記事。体験談ではなく **確認手順・比較表** で差別化（嘘を書かずに作れる）
3. **リンク方式**：最初は **Amazon検索結果リンク**（商品切れ・ASIN間違いで死なない）。売れた商品が分かったら個別ASINリンクに差し替え
4. **集客**：X（旧Twitter）で「デスク環境」系の有益投稿を毎日 → 記事へ誘導

## マイルストーン
| 時期 | 目標 | やること |
|---|---|---|
| 0日目 | 公開 | 5記事でサイト公開 → アソシエイト申請 → Search Console登録 |
| 〜2週 | 10記事・X毎日投稿 | `/cycle` を週2回 |
| 〜1か月 | 初クリック・初売上 | X投稿の反応が良いテーマで記事追加 |
| 〜3か月 | 適格販売3件（正式承認） | 20記事、売れた記事の横展開 |
| 承認後 | 月1万→月5万 | PA-API で商品カード化、売れ筋記事のリライト |

## 週次サイクル（`/cycle` コマンドで自動実行）
1. performance-analyst：データがあれば分析
2. keyword-researcher：キーワード2件
3. article-writer：記事2本
4. compliance-checker：規約監査（ERROR 0）
5. sns-promoter：投稿案を sns/queue.md へ
6. build → git push で自動公開
