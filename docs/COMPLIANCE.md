# 規約・法令チェックリスト（必ず守る）

## Amazonアソシエイト運営規約
- [x] 定型文「Amazonのアソシエイトとして、〇〇は適格販売により収入を得ています。」をサイトに表示（全ページのフッター・運営者情報）
- [ ] 価格を直書きしない（PA-API経由のみ可。変動するため誤表示＝違反リスク）
- [ ] Amazonの商品画像を保存・転載しない（PA-APIまたはSiteStripeの画像リンクのみ）
- [ ] Amazonのレビュー本文を転載しない
- [ ] リンクをメール・PDF・電子書籍・オフライン媒体・LINE等の非公開の場で使わない
- [ ] 自己購入・家族友人への購入依頼をしない
- [ ] 短縮URLは amzn.to（公式）のみ。他の短縮サービスで偽装しない
- [ ] 申請時に登録したサイト・SNSアカウント以外でリンクを使う場合は、アソシエイト・セントラルでサイト情報に追加する

## 景品表示法（ステマ規制・2023年10月〜）
- [x] 広告である旨を明示（ページ上部PRバー、記事冒頭の注記、PRラベル）
- [ ] SNS投稿にも「#PR」または「#広告」を付ける
- [ ] 「最安値」「No.1」など根拠のない最上級表現を使わない

## 体験・薬機法
- [ ] 使っていない製品を「使ってみた」と書かない
- [ ] 健康・美容系で「治る」「痩せる」など効果を断定しない（本サイトの「首の疲れ」記事は一般的な姿勢の話に留めている）

`python3 check.py` で機械チェックできる項目は自動検出されます。
